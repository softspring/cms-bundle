# Security Policy

## Supported Versions

Security fixes are provided for the currently maintained package lines:

| Version | Supported |
| ------- | --------- |
| 6.0.x | Yes |
| 5.5.x | Yes |

## Reporting a Vulnerability

Please report security issues privately to Softspring instead of opening a public issue.

Include the affected package version, a clear description, reproduction steps when possible, and the expected impact.
